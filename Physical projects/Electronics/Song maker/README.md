# Song maker 🎵🎹

# What is it?
"Song Maker" is a simple Arduino project capable of creating a musicbox-like melody with a potentiometer

# How it works?
The speaker's tone is adjustable with a potentiometer, making it higher or lower, and the code gives it a delay between the tones, making it sound like music

# Components
- Speaker or passive buzzer
- Arduino UNO
- Breadboard
- Jumper wires
- Potentiometer

# Future improvements
- Make the delay between the tones also adjustable by adding another potentiometer
