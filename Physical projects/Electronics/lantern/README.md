# Lantern

## Description
A LED lantern made with popscicle sticks and electronics components, made in 03/10/2026 with soldering.

# How it works
Energy leaves the positive side and reaches the board. The board's negative side is connected to the switch button, which you can turn on or off. If it is on, the energy can go back to the batteries.

## Components
- USB LED lamp
- An USB board
- Four AA batteries and the batteries compartment
- Wires
No coding needed
